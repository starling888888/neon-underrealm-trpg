## この文書の位置づけ

- 添付されていた改善項目を、現行のルールサイト／リポジトリ資料と、今回の横断評価結果に照らして精査した。
- 同一IDの重複行は統合し、明示的に許容・棄却された項目と、共通ルールから処理できる項目は本文から除外した。

- 公開済みのプレイヤー向けルールに対しては、数値再設計よりも、矛盾・処理不能・誤読・実装不整合の解消を優先する。

## 最終総合評価

### 結論

初期作成帯におけるゲーム設計と戦闘バランスは成立している。現時点で、流儀・生き様・武器・サンプルキャラクターに対する**確定的な数値調整は不要**と判断する。

本作が狙う戦闘体験である、

- PCの攻撃は概ね当たり、大きなダメージを出せる
- 敵もPCを気絶させられる重量級の火力を持つ
- 覚悟による復帰で戦線へ戻れる
- 攻撃へ資源を使うか、重要なリアクションへ残すかを判断する
- 3ラウンドの中で通常運用、圧力上昇、再起・大技・決着を行う

という構造は、初期作成サンプル10体と旧サンプルボス2体の組み合わせでも確認できた。

一方、公開ルール文書とデータには、ページ間の直接矛盾、共通処理の欠落、個別効果の対象・期間・適用順の未確定、サンプルデータの入力不整合が残っている。これらは数値バランスの崩壊ではないが、第三者のGMが作者判断なしで一意に処理することを妨げる。

したがって、評価は次のように分かれる。

| 評価対象                             | 判定                                                       |
| ------------------------------------ | ---------------------------------------------------------- |
| ゲーム固有の戦闘体験                 | 成立                                                       |
| 初期作成帯の役割分担                 | 成立。明確な上位・下位構成は確認できない                   |
| サンプルキャラクターのショーケース性 | 成立。戦闘役割・名称・非戦闘技能のフレーバーが分化している |
| 初期作成帯の数値バランス             | 確定的な調整不要                                           |
| 3ラウンドの最終戦闘                  | 4人用シバ、3～4人用サクラとも成立                          |
| 公開ルールの自己完結性               | 要改善。高優先度の矛盾・欠落を先に解消する必要がある       |
| GM向け運用                           | 作成フェーズ。三下換算と情報提示基準を追加する必要がある   |

**「刺さる人に85点以上」という体験設計は成立しているが、公開ルールだけで安定運用できる文書品質は、下記の高優先度項目を解消するまで未達**というのが最終判定である。

### 評価範囲

- サイト画像と主要ページ
- 共通ルール、シナリオ進行、戦闘、キャラクター作成・成長
- 全10流儀
- 全4生き様
- 共通スキル
- 武器、防具、お守り、サイバネ、ナノマシン、ドラッグ
- 初期作成サンプルキャラクター10体
- 旧ルール期のボス「外道：シバ」と「外道となったサイトウ・サクラ」、戦闘用ロボット
- 3～4人PT、最終戦闘3ラウンドを前提とした机上評価

### 優先順位

1. **公開ルール基盤の高優先度項目**\
   ページ間矛盾、タイミング、複数体攻撃、コスト、移動、成長、終了処理を先に確定する。
2. **データ・実装の高優先度項目**\
   「攻撃を行う」の欠落、無効レベル、武器効果未反映、サンプルJSON不整合を修正する。
3. **個別効果仕様**\
   基盤ルール確定後に、期間、対象、参照値、適用順を統一する。
4. **表記・UX・性能**\
   挙動を変えない修正としてまとめて対応する。
5. **GM向け項目**\
   プレイヤー向けルールを暗黙に変更せず、三下と敵情報提示の運用を追加する。

## 数値調整・検証状況

### 初期作成帯

初期作成サンプルと旧サンプルボスによる机上評価では、確定的な数値調整は不要。

- 4人用シバは、実質体力450と追加手番を持つ高難度の単体ボスとして、3ラウンド決着圏内にある。
- サクラは、人数に応じた本体体力とロボット数の調整によって、3～4人で3ラウンドの段階戦闘を作れる。
- PC側は高命中・高ダメージを出しやすく、敵側は限定能力で覚悟を要求する火力を作れる。
- リアクションは素の成功率だけでは安定せず、気合、精神力、回数制限、覚悟を投入する攻撃の選択が生じる。
- サンプルキャラクター間には役割差と操作難度差があるが、明確な性能上位・下位は確認できない。

### 実プレイで確認する項目

数値変更を先に行わず、次を観測する。

- 最終戦闘が概ね第3ラウンド内で決着するか
- 覚悟が必須税ではなく、危険な局面で選ばれているか
- リアクション資源の投入判断に必要な情報がPLへ伝わっているか
- 攻撃・リアクション処理の判断時間が許容範囲か
- 防御力の高いボスに対し、特殊攻撃、固定加算、弱体化、支援の役割が機能するか
- 範囲攻撃のない編成でも、取り巻き戦が過度に長引かないか

### 高レベル帯・組み合わせ検証へ持ち越す項目

以下は現時点で修正対象にせず、高レベル敵データと実プレイ環境で再評価する。

- `血毒活性`とBS解除能力の関係
- `精気変転`と他流儀・生き様の精神力コストスキル
- `一撃の本質`と反復型支援・アイテム効果
- サイバネ武器・武器化ナノマシンの取得負担を含めた高レベル性能
